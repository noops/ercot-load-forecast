# ERCOT Load Forecast

Short-horizon load and renewable-output forecasting for the Texas grid.

Status: idea / early prototype. Part of [Bat City AI](https://batcityai.com)'s Year One programs.

## Plan

- **Data**: ERCOT public load data (via ERCOT MIS), NOAA weather observations
- **Stack**: Python, XGBoost or PyTorch, FastAPI
- **Goal**: beat a naive seasonal baseline on short-horizon (hours-ahead) system load, using weather + calendar features

Nothing shipped yet. See [Issues](../../issues) for current plan.
